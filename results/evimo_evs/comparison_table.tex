\section*{Experimental Setup}

\noindent
Evaluated on the EVIMO validation split (13 sequences, DVS346 event camera, 260$\times$346 px).
The DEVO network weights are frozen; only the input event stream varies across runs.
ATE is computed with sim3 (Umeyama) alignment to remove monocular scale ambiguity.

\medskip
\noindent Four configurations are compared:

\begin{enumerate}
  \item \textbf{Original} --- Unfiltered event stream from the raw ROS bags. Ground truth (GT) poses from Vicon absolute world frame.

  \item \textbf{Filter v1} (broken) --- 3D bounding-box projection approach. Flat rectangles used as proxies for 3D toy objects; camera-frame projection had orientation bugs. Net removal: $\approx$0.3\% of events. GT from bags.

  \item \textbf{Filter NPZ / wrong GT} --- Pixel-perfect NPZ masks (13.2\% events removed), but GT derived from NPZ metadata: poses are relative to first frame at $\approx$40\,Hz. \emph{Not directly comparable to runs 1--2; included for completeness.}

  \item \textbf{Filter NPZ / correct GT} --- Same pixel-perfect NPZ masks (13.2\% removed), with GT and frame timestamps taken from the original bags. Fair apples-to-apples comparison with run~1.
\end{enumerate}

\section*{Summary}

\begin{itemize}
  \item \textbf{Filter v1} removed only 0.3\% of events (projection bugs + flat object proxies). Despite this, the mean ATE improved by 14.9\%, suggesting DEVO is sensitive even to small contamination.

  \item \textbf{NPZ pixel-perfect masks} remove 13.2\% of events (median: 10.3\%) using EVIMO's ground-truth per-frame segmentation masks. With the same GT as the original run, this yields a \textbf{22.4\% reduction in mean ATE} (8.14 $\to$ 6.32\,cm).

  \item \textbf{9/13 sequences improve}, 3 slightly degrade (likely stochastic DEVO variance or sequences where the removed events were actually informative background texture).

  \item The run \emph{Filter NPZ / wrong GT} used relative NPZ poses instead of the Vicon absolute frame, which inflated or deflated ATE for individual sequences without being a fair measure of filtering quality.

  \item The biggest gain comes from \texttt{tabletop/seq\_00} ($-$9.79\,cm, 16\% events removed), where the moving object occupies a substantial portion of the field of view.
\end{itemize}
